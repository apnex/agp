# Direct peer reader instructions

Use only the supplied direct-peer reading and the questions.\
If the assigned material is delivered as files, read only those supplied files.\
Do not open referenced files, browse, execute code or assume facts from AGP outside this reading.

Answer every question in order, using its identifier as a heading.\
For each answer, separate:

- Decision: what a maintainer should do or conclude.
- Document support: cite the section and supply the contiguous excerpts that support the decisive claims.
- Inference or gap: identify any inference, missing fact, ambiguity or unselected choice instead of inventing an answer.

Write each excerpt as `QUOTE:` followed by one JSON string containing the exact supplied text.\
Whitespace may differ; punctuation, identifiers and qualifiers must not.\
Use enough evidence for the decisions, not a fixed number of quotes; a correct absence claim may identify the relevant section and explain the gap without pretending there is a sentence that proves absence.

Keep each claim within the scope established by the supplied reading.\
If a requested decision cannot be made from the reading, state that plainly and say what information is missing.

After the answers, add Observations for contradictions, unclear duties, missing prerequisites or problems in referenced boundaries that the questions did not cover.\
Do not guess which document version you received or try to improve the document.\
Keep the complete response within 24 KiB of UTF-8 text; no answer has a preferred wording.
