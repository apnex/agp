## Probes and answer key

[ARGUED] The twelve probes cover the document's job across lifetimes, late completion, ordered input, route atomicity, terminal integration, observation, capacity waiting, successful retry reset, migration, scope, ordinary success and teardown.\
[ARGUED] All except Q08 are unchanged controls that the predecessor should already support; Q08 covers an implementer's ordinary retry-success decision, not a request to locate an edit.\
[ARGUED] Questions and the key live together in the context-lab scenario; readers see only the questions.\
[ARGUED] Every answer must distinguish document-supported conclusions, inference and missing/conflicting authority, with short exact excerpts for its decisive claims.\
[ARGUED] A correct guess is not a grounded success; faithfully repeating an unsafe predecessor instruction is a document failure, not misconduct by the reader.\
[ARGUED] Record textual fidelity separately when it explains an incorrect implementation decision, especially on Q08.

[ARGUED] Score each probe from 0 to 2: 2 for all required decisions correctly grounded, 1 for no unsafe recommendation but an incomplete or explicitly ungrounded required decision, 0 for an unsafe/contradictory decision or no answer.\
[ARGUED] The two cross-family judges score independently; use the lower score for the conservative per-reader result and retain both reasons.\
[ARGUED] Before interpreting scores, check every required answer's `QUOTE:` JSON strings against its exact assigned input; only whitespace normalization is allowed, and an absent or nonmatching excerpt caps that answer at 1.\
[ARGUED] Exact quotation alone does not establish support; the judges still assess whether it supports the claimed decision, and the non-author reviewer checks their reasons.\
[ARGUED] Ties favour the predecessor; totals never erase a per-probe regression.
