# Admission evaluator static qualification amendment

Tier 3: prospective design, selected by the director's continuation of the [compatibility recommendation](../admission-evaluator-compatibility-review.md).\
This qualifies a candidate for a later diagnostic decision, not live execution or AGP adoption.

## Mechanics

Qualify unchanged public context-lab revision `e705b3d749400d0a79efe98e5338e9c84a1695b8` for AGP's instruction-only, single-phase evaluation shape.\
The [source findings](../admission-evaluator-compatibility-findings.md) establish why this candidate is being considered.\
The existing preparation's independent PASS remains scoped to its own checkpoint; it does not transfer to this revision.

| Concern | Mechanism | Falsifier |
|---|---|---|
| Exact evaluator | Verify every exported tracked file against the candidate object, force-build in scratch, import only its public index | Any differing byte or unverified build |
| One panel test | Add an optional profile-path input to the existing capture-only test; retain its original default and all assertions | Changed default evidence beyond temporary paths or lost assertions |
| Delivery restriction | A project precondition checks declared instruction-only arms, no hooks/transforms, and empty folder-file/on-request lists in every publicly composed reader arm and the judge arm | A disallowed declaration or assembled arm is accepted |
| Effective phase restriction | Use public `phasesOf` and `propertyPhase` on resolved scenarios; require exactly one fresh `answer` phase, all properties on it, no traps, notes, branching, fixture or held-out split | A scenario override bypasses the restriction |
| Frozen population | Exact original population, model routes/settings, factors, judges, run count and wall limits; no selected live cap | Changed member, family, limit or denominator accepted |
| Panel fidelity | Fresh complete and missing-reader captures through the existing public blinder/panel test, with complete prompts, replies, jobs and original votes | Counters substitute for full records, or absent outcomes acquire invented votes |
| Ordinary episode records | Public `runEpisode` with an injected local synthetic runtime writes only an unrelated library answer in scratch; inspect its one phase, ledger trees, snapshot, raw outcome and answer file | Lost fields, wrong phase or mismatched file/diff |
| Tally compatibility | Re-tally fresh synthetic panel records through public `tally`; compare all legacy score/accounting fields with the original frozen evaluator, plus explicit ended/incomplete ordinary record fixtures | Changed scores, denominators, missing answers or failure dispositions |
| Conductor compatibility | Read exact source deltas, trace fresh-run retry/phase/scoring/record paths; exclude resume and restricted-run tally | Source-only review is reported as an executed conductor or live proof |

The profile and restrictions live in this new qualification directory.\
The optional input to the existing test resolves profile references relative to that profile; it does not duplicate the test or change scoring.\
An invalid restriction is tested as inert configuration or record data, never submitted to a provider, sandbox or probe.\
Ordinary synthetic episode execution is development evidence only; it neither invokes a real runtime nor qualifies isolation.

## Invariants and evidence

1. Preserve the original FAIL, later NO VERDICT, frozen packets, existing policy, fixtures, reviewed profiles and independent reports unchanged.
2. Carry preparation guardrails G1-G6: original raw votes, conservative accounting, independent semantic review of favorable and unfavorable judgments, fixed population, no live calls and distinct configured/client/backend budget observations.
3. Keep the only existing-preparation code change to selecting and resolving an optional test profile; rerun the historical default to establish regression parity.
4. Build actual reader arms through public variant/composition interfaces using the frozen source revision; no copied evaluator logic or patched upstream source.
5. Assert both declarations and assembled structures; the missing newer tools-off mount guard is acceptable only while every on-request list is empty.
6. No automatic resume, scenario holdouts, phase branches, hooks or new delivery mechanisms enter this qualification.
7. Retain full synthetic evidence and test outputs, including failures, separately from historical captures; label them with exact source identity and zero model calls.
8. Record source observations separately from the compatibility judgment; source equality and test success are author evidence, not independent assurance.

Changed conductor behavior is source-reviewed, not exercised by a full synthetic run that would also execute probes.\
The normal episode check covers the new ledger's ordinary record production; it does not reproduce history leaks, repository corruption, escapes or other security-triggering cases.\
Pure tally checks concern inert disposition records, not execution of the failures those records describe.

## Rationale and consequence

Using an unchanged public revision keeps shared evaluator behavior upstream while mechanizing AGP's bounded preconditions.\
An optional profile input avoids a second panel implementation and preserves reproduction of the historical default.\
The single-phase restriction removes branch/resume assumptions from this qualification, while positive episode records and pure tally parity address changes that still affect this shape.\
Independent review decides whether those bounds are sufficient for static qualification; no live assurance is inferred from them.

B53 stays open, B56 is unaffected, and no push, upstream contact, Zorg response or AGP runtime implementation is authorized by this amendment.
